❓ Aide - Utilisation de ScanProf

📌 Fonctionnement général

ScanProf collecte les résultats d’élèves via des QR codes JSON (RunStats, ClimbTrack, autres outils). Chaque scan alimente un tableau central, que vous pouvez trier, filtrer, exporter ou partager.

Le flux est toujours : générer un QR à la fin d’une séance → scanner avec ScanProf → traiter dans les tableaux ou exporter pour les partager. L’application accompagne aussi des projets comme le ZENOS Tour.

📷 Scanner 👥 Participants 🗂 Classes & séances ➕ Créer une classe ❓ Aide

🏠 Accueil

  • Scanner : lance le lecteur QR pour ajouter des élèves.
  • Participants enregistrés : tableau central pour trier, filtrer, exporter/importer CSV, et générer un PDF.
  • Groupes ZENOS Tour : crée des groupes de 4 équilibrés automatiquement.

📷 Scanner un QR Code

  • Placez un QR code (format JSON) devant la caméra.
  • Les QR peuvent contenir 1 ou 2 élèves. Les doublons sont évités (nom+prénom+classe).
  • Chiffrement ? Non, simplement la remontée de données lisibles pour les tableaux.

👥 Participants enregistrés

  • Mode édition : actif par défaut, il est symbolisé par le bouton violet ✏️. Touchez un champ pour écrire, utilisez Tab pour naviguer et “Ajouter un élève” ouvre une nouvelle ligne vierge.
  • Colonnes personnalisées : les boutons “Ajouter/Supprimer une colonne” modifient l’architecture du tableau, leurs réglages sont stockés dans le navigateur.
  • Menu déroulant : un détail “Options d’écriture” rassemble toutes les actions d’édition (colonnes, lignes, mode). Une autre rubrique “Options d’archivage” contient les exportations, l’impression et l’archivage vers vos classes.
  • Tri + filtre texte : triez sur n’importe quelle colonne, filtrez sur des mots-clés (ex. “Lola”, “5A”, “F”).
  • Navigation rapide : la barre en bas conserve les raccourcis Accueil, Scanner, Classes & séances, Aide et Groupes ZENOS.

🗂 Classes & Séances

Chaque classe est un dossier. Sur la page “Classes” vous créez une classe (nom + couleur), puis pour cette classe vous ouvrez la liste des activités. Chacune de ces activités est un sous-dossier dans lequel vous pouvez créer autant de séances que vous le souhaitez.

  • Une activité par dossier : badminton, escalade, français… : vous pouvez ajouter/modifier/supprimer une activité autant de fois que nécessaire.
  • Séances archivées : à l’intérieur d’une activité, chaque séance est un tableau complet (comme sur “Participants”). Vous pouvez renommer la séance, ajouter/supprimer des colonnes, saisir des données ou les exporter.
  • Connexion avec la page Participants : depuis cette page, le bouton “💾 Archiver dans mes classes” copie un tableau dans la classe/activité choisie.
  • Modifier en continu : sur les pages d’activités, le même éditeur de tableau est disponible (mode écriture, colonnes personnalisées, lignes) – vous avez une flexibilité totale.
  • Sauvegarde : tout reste local. Exportez régulièrement pour garder une copie dans Fichiers, Drive ou iCloud.

🔄 Synchronisation Participants ↔ Classes

Chaque tableau que tu vois dans “Participants enregistrés” peut être envoyé vers ton classeur local : il suffit de cliquer sur 💾 Archiver dans mes classes, de choisir une classe, puis une activité pour déplacer la séance dans un dossier dédié.

  • Renommer une classe ou une activité actualise immédiatement l’arborescence : si une séance n’apparaît pas, vérifie que tu l’as archivée dans la bonne classe/activité.
  • Exports : les CSV/PDF produits depuis Participants sont identiques à ceux que tu peux générer depuis Chaque activité (bouton “Exporter CSV” sur les séances).
  • Réouverture : les séances archivées s’ouvrent avec le même éditeur (mode écriture et colonnes personnalisées) que celui de Participants, donc tu peux continuer de travailler dessus après l’archivage.

💾 Sauvegardes & exports

Toutes les données restent stockées localement. Exportez vos tableaux régulièrement pour éviter une perte liée au cache du navigateur :

  • CSV : au niveau d’une activité ou d’une classe entière.
  • Impression / PDF : disponible dans la page Participants avant d’utiliser le partage iOS/Android.
  • Copie manuelle : stockez les exports dans Fichiers, Drive, iCloud ou un dossier partagé.

📤 Partager le PDF depuis iPad/iPhone

Pour envoyer la liste des participants en PDF par mail (ou l’enregistrer dans Fichiers) :

  1. Dans Participants enregistrés, touchez 🖨️ Imprimer / PDF.
  2. Dans la fenêtre d’aperçu iOS, touchez l’icône de partage en haut à droite.
  3. Choisissez Mail, Messages ou Enregistrer dans Fichiers.

Astuce : vous pouvez aussi AirDrop le PDF vers un Mac.

🧬 Groupes ZENOS Tour

Création de groupes de 4 élèves équilibrés selon la VMA (un haut, un bas, deux intermédiaires). Les classes sont normalisées automatiquement (ex. “5ème A”, “5A”, “5 a”… → 5A) afin d’éviter les erreurs de saisie.

  • Affichage en un seul tableau avec groupes alternés (bleu/blanc).
  • Élèves à attribuer manuellement listés en bas (couleur différente).
  • Actions : CSV, Imprimer, PDF, Mail.
